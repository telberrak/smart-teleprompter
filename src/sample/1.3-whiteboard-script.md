# 1.3 What is an API?

[ON SCREEN: step 1]
{intro} Welcome back. In this lesson we look at how an API lets two programs talk.

{key} Think of an API as a **waiter** in a restaurant. [pause 1s]

[ON SCREEN: step 2]
{ex} You read the menu, / you place an order, / and the kitchen does the work.
{ex} You never walk into the kitchen yourself. [pause 2s]

[ON SCREEN: step 3]
{def} In software, your app is the customer and the server is the kitchen.

[ON SCREEN: step 4]
{key} The **request** goes out, / and a **response** comes back.
{def} That response is usually written in JSON, which is a simple structured text format that both of the programs are able to read and understand.

{key} So the API is really a **contract** between the two. [pause 1s]

[ON SCREEN: step 5]
